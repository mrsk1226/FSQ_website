# FSQ Website — Four Square Fenestration

Static website for **Four Square Fenestration** (Erode) — uPVC windows & doors,
aluminium windows & doors, and home interiors.

## Structure

- `index.html` — the full single-page site (hero, products, catalogue, contact)
- `assets/` — images, product renders, test certificates & PDFs
- `icon.jpg` — site icon

## Run locally

Any static server works, e.g.:

```bash
python3 -m http.server 8080
```

then open http://localhost:8080
