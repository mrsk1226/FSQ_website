# 01 — Prominance uPVC (prominance.com)

**Source site:** https://prominance.com/upvc-windows-upvc-doors/
**Role in clone:** the factual backbone of all uPVC content — certificates, test data,
profiles, colours, testing, warranty, hardware, and the 14-file Downloads library.
**Branding rule:** content used, "Prominance" name/logo/partner badges NEVER used.

## Page structure (as captured)

1. Hero — "20 Years Warranty for Complete Peace of Mind" headline
2. Certificates strip (SKZ / BSI / SGS / CIPET / ISO references)
3. Quality claims (25,000 hrs weather testing, UV, lead-free, sound, energy)
4. Profile systems (INVENTA / OPTIMA, chambers, steel reinforcement, gaskets)
5. Window types (Inventa Casement / Sliding / Tilt & Turn, Optima Casement / Sliding)
6. Door types (Inventa Casement / Sliding / Slide & Fold)
7. Colours — 12 laminate swatches + white
8. Testing section (wind-load 1500 Pa, drainage, strengthening bars)
9. Hardware & glazing options
10. Warranty block
11. Downloads / resources link

## What was USED vs NOT used

**USED:** every certificate name + test standard + result figure; all quality claims;
profile system names INVENTA/OPTIMA (dev-site's own product names, kept); wall-thickness,
steel, gasket, welding specs; all 12 laminate colour names; 1500 Pa wind-load figure;
20-year warranty; hardware list; all 14 PDFs mirrored into the clone's Downloads library.

**NOT used:** the "Prominance" brand name anywhere; "channel partner" badges;
company address/phone/email; marketing slogans; pricing pages.
